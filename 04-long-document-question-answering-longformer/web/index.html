Responsible use and limitations

This educational portfolio demo may return incomplete, incorrect, unsupported, or misleading answers. The confidence value is a model output score, not a calibrated probability. Always inspect the supporting paragraph. Do not upload confidential, proprietary, sensitive, copyrighted, regulated, or personally identifiable documents. Do not use the result as the sole basis for legal, medical, financial, safety-critical, academic, official, quality-release, or business-critical decisions.
