# Portfolio Positioning

## One-line description

Built a deployment-ready Longformer document QA system that answers questions
over uploaded long documents and returns a confidence proxy, supporting
paragraph, highlighted evidence, and context-length diagnostics.

## GitHub pinned-repository description

Long-document extractive QA with Longformer, overlapping token windows,
evidence grounding, Exact Match/F1/evidence-recall evaluation, Gradio, tests,
CI, and Hugging Face Spaces deployment.

## Skills demonstrated

Transformer inference, Longformer global/local attention, extractive QA,
tokenizer overflow handling, span extraction, offset mapping, document parsing,
evidence highlighting, confidence communication, evaluation, error analysis,
Gradio, Hugging Face Hub, Docker, testing, and GitHub Actions.

## Quality Data Scientist connection

The project demonstrates a safe prototype for searching long quality reports,
GCS case histories, SOPs, technical manuals, CAPA documents, complaint
investigations, supplier reports, and quality knowledge bases. It shows how a
Quality Data Scientist can move from descriptive analytics into Document AI,
evidence-grounded NLP, and deployable Applied AI systems without claiming that
the demo is ready for regulated decision-making.
