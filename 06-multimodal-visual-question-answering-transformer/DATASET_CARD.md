# Dataset Card — Project 06 VQA Data

## Demo dataset

The repository contains three safe synthetic sample images and three
question-answer records used for smoke tests and the interactive interface.

## Balanced browser evaluation dataset

The project also includes a generated 60-pair synthetic VQA evaluation suite:

| Category | Records |
|---|---:|
| Color | 10 |
| Object identification | 10 |
| Counting | 10 |
| Yes/no | 10 |
| Action or scene | 10 |
| Spatial relationship | 10 |
| **Total** | **60** |

Files:

```text
data/evaluation/vqa_evaluation_60.json
data/evaluation/vqa_evaluation_60.csv
data/evaluation/images/
```

Static Space copies are stored under `space/evaluation/` so the same records
can be evaluated entirely in the browser.

## Record schema

- `id`
- `image`
- `question`
- `accepted_answers`
- `category`

## Generation and validation

The images and records are deterministically generated by:

```bash
python scripts/generate_synthetic_evaluation_set.py
```

Validate the committed suite with:

```bash
python scripts/generate_synthetic_evaluation_set.py --check
```

The validation requires exactly 60 records, 10 per category, non-empty accepted
answers, and existing images in both project and Static Space locations.

## Scoring scope

The browser uses normalized accepted-answer matching with limited containment
for short generated answers. This is suitable for portfolio diagnostics but is
not equivalent to official VQA v2 consensus scoring.

## VQA v2 compatibility

The Python loader and evaluator support VQA v2-style fields including image,
question, multiple human answers, question type, answer type, and split. The
full VQA v2 dataset is not redistributed.

## Limitations

Synthetic shapes and simplified action scenes do not represent natural-image
diversity. Results can overestimate or underestimate real-world performance.
Use a larger held-out dataset before making reliability claims.

## Sensitive data and responsible use

The committed images are project-generated and contain no real people or
private information. Do not add personal photos, IDs, medical images,
confidential workplace content, sensitive personal information, or copyrighted
images without authorization.
