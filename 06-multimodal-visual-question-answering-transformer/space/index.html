How the static deployment works

  1. The image stays in the browser and is converted into model-ready pixels.
  2. The question is normalized without removing meaning-bearing words.
  3. Quantized Moondream2 ONNX components are downloaded from the Hugging Face Hub.
  4. WebGPU performs vision-language generation and returns the answer.

Limitations

The model can miss small objects, miscount, hallucinate, struggle with OCR, or answer ambiguous questions incorrectly. Browser performance varies by hardware, driver, memory, and network speed.
