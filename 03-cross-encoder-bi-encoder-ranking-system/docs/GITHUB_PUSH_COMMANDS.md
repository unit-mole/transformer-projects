# GitHub Push Commands

Run these commands from the root `transformer-projects` folder:

```bash
git add "03-cross-encoder-bi-encoder-ranking-system" ".github/workflows/03-cross-encoder-bi-encoder-ranking-system.yml"
git commit -m "Update Project 03: Add Python, Model Hub and Static Space architecture"
git push origin main
```

These commands stage only Project 03 and its dedicated workflow.
