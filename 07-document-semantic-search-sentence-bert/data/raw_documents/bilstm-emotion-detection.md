# Emotion Detection with BiLSTM and Attention

## Objective
Classify text into emotion categories using a bidirectional LSTM and an attention mechanism. The model captures left-to-right and right-to-left context, while attention surfaces influential tokens.

## Evaluation
The project reports macro F1, weighted F1, class-level recall, confusion matrices, and error analysis for sarcasm, mixed emotions, and short messages. It provides a useful sequence-model baseline before Transformer-based text classification.
