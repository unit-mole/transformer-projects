# Neural Machine Translation Transformer

## Objective
Create an English-to-Hindi neural machine translation application using an encoder-decoder Transformer. The system handles tokenization, batched inference, translation examples, and language-specific error analysis.

## Metrics
The project reports BLEU, chrF, sentence-level examples, inference latency, and manual review of named entities, word order, transliteration, and meaning preservation.

## Deployment
A free Hugging Face Spaces demo lets users enter English text and view Hindi translations. The project separates training, evaluation, and deployment code.
