# ML Portfolio Deployment Overview

## Deployment diversity
The Transformer portfolio uses free deployment platforms according to application requirements. Hugging Face Spaces supports Python and model-centric demos. GitHub Pages supports static browser AI projects that can run with JavaScript, Transformers.js, TensorFlow.js, or precomputed outputs. Vercel supports a polished RAG assistant with serverless application routes when needed.

## Engineering standards
Each project includes a professional README, reproducible scripts, tests, data and model cards, responsible-use notes, output artifacts, deployment instructions, and a GitHub Actions workflow. Live links and screenshots make recruiter review faster.
