# Multimodal Visual Question Answering Transformer

## Objective
Answer natural-language questions about an uploaded image using a vision-language Transformer such as ViLT. The application combines image preprocessing, text tokenization, multimodal attention, answer ranking, and confidence-aware presentation.

## Evaluation
The project records VQA accuracy, answer-type performance, latency, qualitative examples, and failure analysis for OCR, counting, spatial relationships, and out-of-domain images.

## Deployment
The demo is packaged for Hugging Face Spaces with a public sample-image policy and a responsible-use disclaimer.
