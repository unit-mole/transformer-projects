# Instruction-Tuned Domain LLM

## Objective
Adapt a compact language model to follow domain-specific instructions using supervised fine-tuning and parameter-efficient LoRA adapters. The project emphasizes reproducible prompt formatting, safe data preparation, evaluation, and transparent limitations.

## Evaluation
The analysis covers instruction-following quality, exact-match tasks, semantic similarity, latency, failure categories, and manual review. It does not claim domain expertise or safe autonomous decision-making.

## Deployment
Model artifacts and an interactive demonstration are prepared for Hugging Face. Private company data is excluded from training and examples.
