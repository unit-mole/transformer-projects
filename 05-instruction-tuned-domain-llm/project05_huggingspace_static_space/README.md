# Project 05 — Instruction-Tuned Domain LLM

A free static Hugging Face Space presenting two FLAN-T5-base LoRA experiments,
an 80-prompt benchmark, automated metrics, direct human review, the complete
project workflow, and the final release decision.

## Application highlights

- Model-performance dashboard
- Experiment 1 and Experiment 2 training comparison
- Base vs tuned-model evaluation metrics
- Human preference results
- Interactive 80-prompt benchmark explorer
- Reference, base, Experiment 1, and Experiment 2 answers
- End-to-end workflow and release-quality gate
- Known limitations and responsible reporting

This Static Space displays saved experiment evidence. It does not run Python
model inference.
