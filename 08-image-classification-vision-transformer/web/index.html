EXPLAINABILITY

Patch sensitivity, honestly labeled

The deployed ONNX classification graph does not expose raw transformer attention. This demo therefore masks image regions, reruns the model, and measures how much the selected class score changes.

This is not raw attention. It is a real perturbation-based sensitivity test. Genuine class-token attention rollout can be generated in Python from a compatible checkpoint using the included script.

How the live map works

  1. Divide the image into a 4 × 4 grid.
  2. Mask one patch at a time.
  3. Run a new model prediction.
  4. Compare the selected class score with the original score.
  5. Overlay larger score reductions as stronger sensitivity.

Sixteen additional inferences are required, so this step can take time on CPU/WASM.

LIMITATIONS

What reviewers should know

  • The starter predicts ImageNet labels, not CIFAR-10 labels.
  • First load requires public model assets from the Hugging Face Hub.
  • Latency depends on device, browser, cache, and execution provider.
  • Confidence is not guaranteed to be calibrated.
  • Patch sensitivity is not proof of model reasoning.

Portfolio upgrade path

Fine-tune the compact model on CIFAR-10 or Intel scenes, export a quantized ONNX checkpoint, validate Python-versus-browser parity, generate real attention rollout, and compare against the prior ResNet project.
